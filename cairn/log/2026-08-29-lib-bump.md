# Moved onto the current libraries

Sirup builds again against pimalaya-stream 0.3, io-imap 0.6, io-smtp 0.3, io-sasl 0.1 and pimalaya-config 0.2.

The SASL credential structs now come from io-sasl, declared as a direct dependency with its `scram` feature on: the `Sasl` enum names the profile and its credentials carry the channel binding, so SCRAM-SHA-256 passes an empty nonce for the client to draw and `SaslGs2ChannelBinding::Unsupported`. The two connects take an options struct rather than a list of arguments, both return the negotiated capabilities beside the client, and `noop` moved behind the `ImapClient` and `SmtpClient` traits. `Secret::Command` holds a `CommandConfig` now, so the wizard writes `CommandConfig::Argv` for a picker's argv and `CommandConfig::Shell` for a hand-typed line rather than building a `std::process::Command`.

The one behavioural change is the stream retry strategy. `StreamStd` became `Stream`, and a stream now retries what a socket reports as not ready, for a minute by default. The proxy loop is built on the opposite promise, reading a `WouldBlock` as "nothing to relay this pass", so every idle pass would have stalled for a minute and then failed as a timeout. `Session::set_nonblocking` sets both together: `Retry::Never` going into non-blocking mode, the default coming back for the keepalive NOOP. The two downcast sites also collapsed into one `Session::stream` accessor, the third caller being what earned it.

Capabilities moved: socket-proxy.
